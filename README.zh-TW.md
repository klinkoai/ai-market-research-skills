## 12 個市場研究 Skills

依照眼前需要做出的決定選擇對應 Skill。每個 Skill 都定義專門的輸入、判斷標準、證據邊界、輸出與下一步驗證。

12 個 Skills 包括受眾發現、細分受眾、受眾比較、市場機會、創業想法驗證、早期採用者、買家人物誌、客戶痛點、定位、內容策略、創意簡報與傳播模式分析。

每個 Skill 都有獨立的公開介紹頁，包含示例、能力邊界和相關研究決策。
